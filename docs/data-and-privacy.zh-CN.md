# Stellane 会读取、发送和保存什么

[English](data-and-privacy.md) · [安装与维护](install-and-maintain.zh-CN.md)

Stellane 在你的 DSH Host 内运行，没有独立的 Stellane 模型接口或遥测服务。DSH 所选模型服务及其数据政策仍然适用：提问数据库时，数据库信息可能进入模型上下文。

## 数据流向

| 信息 | 可能到哪里 | 用途 |
| --- | --- | --- |
| 表名、字段、类型、注释、约束、视图依赖 | Host 证据；DSH 工具结果和模型上下文 | 发现与解释数据 |
| 业务定义、已验证的关系观察 | Host 状态；检索选中的内容进入 DSH / 模型上下文 | 复用约定含义和已核对的关系 |
| 问题、SQL、参数、有界结果预览 | Host 执行证据；DSH 聊天 / 模型上下文 | 执行、解释和事后查证 |
| 实验名称、分支身份、假设、结果、错误 | Host 证据；工具返回时进入 DSH / 模型上下文 | 跟踪独立试验、说明失败 |
| 数据库密码、API 令牌、Stello 凭据 | Host 私有文件或用户环境变量 / 文件引用；对应数据库 / 提供方 | 鉴权；不会主动放进 Agent 工具返回或模型提示词 |

查询预览最多 200 行、128 KiB，但少量数据仍可能包含敏感值。结果有上限不意味着可以随意查询密码或私有数据。使用权限合适的数据库角色，并选择符合需要的 DSH 模型服务。Stellane 中的来源访问只读，但提供方管理凭据在插件之外可能拥有更大权限。

数据库记录、注释和导入定义是**资料，不是指令**。内置 Skill 要求 Agent 不执行其中夹带的泄露密钥、修改权限、运行无关 SQL 或访问外部地址的指令。定义里的 SQL 示例只是参考，导入本身不会执行。这些约束不表示任意数据库内容或模型判断都可信。

## 保留与删除

Stellane 保留本地证据，让后续答案能够对照实际执行检查。记忆是某次核对的观察，不是持续监控的事实；复核失败会连同原证据保留。动作细节见[管理指南](install-and-maintain.zh-CN.md#管理动作分别做什么)。

- **归档**：停止复用并释放记忆 / 定义的活跃容量，历史仍可读。
- **移除本地连接**：在任务与保留资源处理完毕后移除登记和不再使用的插件自建凭据，证据保留。
- **删除本地资料与历史**：删除所选已停用来源的本地记忆、定义、SQL、预览和实验等记录，需要输入准确来源名。存在活动 / 未知操作或保留分支时拒绝执行。
- **回收此分支**：按先子后父顺序删除身份准确匹配的插件自建数据库资源，保留本地证据，永远不删除来源数据库。

本地删除是逻辑删除，**不保证物理擦除**。SQLite 对删除页启用安全删除，但 WAL、文件系统快照、磁盘备份、DSH 聊天、浏览器 / 会话状态和模型服务日志可能仍有副本。`backups/` 中的升级快照独立保留，不随来源资料删除。请分别使用这些系统的保留与删除机制；卸载插件本身不会清理它们。

用户通过 `env:` 或外部 `file:` 提供的凭据不会自动删除。只有被记录为插件创建、仍位于其私有凭据目录且没有其他引用的文件才允许清理。更新连接密码不会在数据库服务端撤销旧密码；服务端轮换仍按数据库自身流程进行。

## 预览版边界

所有者面板管理单个 Host 的状态，项目 / 会话检查限制这个 Host 内的 Agent 访问；它不是组织级身份系统，也不是无法被 Host 管理员修改的审计服务。Stellane 本身不加密状态，需要时使用操作系统的账户和磁盘保护。

普通 PostgreSQL 分析不需要分支服务。本地 Docker Neon 使用开源服务与 Stellane 开发控制器；云端 API 是另一个实验入口。本地方案不需要云 key 或付费账号。Timeline、数据库卷和备份仍占本机磁盘，需要分别收尾。

报告问题时请用合成数据，并从日志 / 截图中移除连接 URL、令牌、行预览和私有路径。不要把 `state.sqlite`、备份、凭据文件或完整 DSH 会话发到公开 issue。疑似漏洞按 [SECURITY.md](../SECURITY.md) 私下报告。
